# Source Agent Guide

This directory contains the Worker app, route adapters, Effect services, JSX UI,
SDK, and tests.

## Boundaries

- `index.ts` wires runtime concerns: Hono app, UI auth middleware, scheduled
  jobs.
- `router.ts` is generated by `bun run routes`; avoid manual route registration
  edits unless regenerating is impossible.
- `routes/` owns request/response adapters.
- `lib/effect/` owns domain behavior and typed failure modes.
- `components/` owns reusable server-rendered UI.
- `db/schema.ts` is the source of truth for D1 tables and Drizzle-inferred
  select/insert types.
- `sdk/` is client-facing API surface and should avoid server-only imports.

## Imports

- Use `@/` for app imports.
- Use `@client/` only for browser client code under `src/client`.
- Keep type-only imports as `import type`.
- Import persisted row types directly from `@/db/schema`. Keep `src/types.ts`
  for cross-cutting app types such as `Env`, `TenantScope`, and UI filter
  helpers, not database record aliases.

## Runtime Constraints

- Code must run in Cloudflare Workers unless it is under `src/test` or
  `scripts`.
- Do not add Node-only APIs to Worker paths.
- D1 access goes through repositories or explicit query helpers; keep raw SQL
  isolated and parameterized.
- Worker routes should return `Response`, `c.json`, `c.html`, `c.text`, or
  `c.render` directly.

## Error Handling

- Expected domain failures should be typed Effect errors.
- HTTP adapters should map those errors with `errorStatus`.
- Unexpected exceptions should be avoided in route code; wrap async/platform
  calls in Effect services where practical.

## Adding Features

1. Decide whether the change is route, service, repository, UI, SDK, or script
   work.
2. Add/adjust Effect schema types first for new ingest/API payloads.
3. Add repository changes and migrations for persistence, deriving DB-facing
   TypeScript types from `src/db/schema.ts`.
4. Add routes/UI after domain behavior is covered.
5. Add tests at the same layer as the behavior.
6. Run the commands from the root `AGENTS.md`.
